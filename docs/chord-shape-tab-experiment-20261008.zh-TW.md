# 和弦指型輔助 TAB：第一輪實驗

在「調弦與譜面設定」新增「參考和弦指型（實驗）」選項，預設關閉，僅適用標準吉他調弦。開啟後，瀏覽器背景 worker 會把目前和弦時間軸的候選指型，當作連續 TAB 弦／格數配置的軟性線索；音高、起音及人工指定的弦格不變。必須先有至少兩種可辨識和弦音、音符與和弦音階充分吻合、候選指型覆蓋至少一半和弦音，才會使用這項線索。不吻合或低信心的段落略過。不同指型可以在同段內比較，但換指型有成本。Capo 會先換算成相對指型；其他調弦及 Bass 不使用此功能。

使用既有 12 段 GuitarSet 錄音的**預測和弦**及人工 TAB 標註測試；標註只用於評分，不傳入配置器。參考資料可能與既有模型訓練資料重疊，不代表公開歌曲準確率。

| 弦／格數一致率 | 原本 | 加入和弦指型 |
| --- | ---: | ---: |
| 開發組，參考模型弦位 | 0.9068 | 0.9060 |
| 回歸組，參考模型弦位 | 0.9206 | 0.9206 |
| 開發組，重新配置易彈把位 | 0.7244 | 0.7940 |
| 回歸組，重新配置易彈把位 | 0.5031 | 0.4688 |

以較強權重測試時，模型弦位模式的整體一致率由 0.9114 降至 0.9057。因此目前不設為預設、不改寫 MIDI 或儲存譜；使用者可以自行開關比較。和弦標籤若不準，這個方法仍可能選錯弦位；下一步應取得獨立、人工確認的和弦加 TAB 對照，並分別評估刷弦、分解和弦與旋律。

重跑比較：`.venv/bin/python tools/evaluate_chord_shape_assist.py <既有報告.json> <輸出.json>`；加 `--playable` 比較不參考模型弦位的模式。實驗輸出放在 HDD 的 `benchmarks/note-plausibility-20261008-v1/`，不屬於正式模型。
