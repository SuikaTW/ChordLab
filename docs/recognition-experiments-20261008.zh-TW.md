# 和弦／TAB 五項實驗紀錄

本次的比較對象是既有的 `event_verified` 建議譜，使用相同 12 段 GuitarSet 錄音與同一份標註。這個資料集可能與既有模型訓練資料重疊，因此數字只用來找退步，不能宣稱公開歌曲的準確率。

1. **和弦時間與連續性**：新增 20 ms 精度的聲學切點細修，以及只在已通過局部音訊驗證的候選中搜尋前後段最一致的和弦。另測試了全面微調 Chordino 切點：development 的和弦時間一致率 0.5361→0.5403，但 regression 0.2070→0.2020，邊界 F1 0.3457→0.2222，所以沒有啟用全面微調。
2. **快速音符與重撥**：在兩個獨立模型起音足夠接近且原音訊有音頭時，允許檢查較短的事件。12 段完整對照的音高／起音 F1 從 0.899718 降到 0.899487；未設為預設。
3. **連續 TAB 指法**：指法搜尋增加同時按住的品位數成本與重複和弦手型的軟性偏好；保留音高、空弦、Capo、變調弦與人工指定弦格。和第 2 項合併測試時，實際顯示 TAB 的 F1 由 0.905360 降到 0.905128，弦格一致率維持 0.911412。需要更細的分項測試才能確認哪些奏法受益；實驗旗標預設關閉。
4. **重複樂句**：用相同錄音中的 3 秒聲學圖樣對齊，支援小範圍速度變化；若對應段落缺音，就在建議譜中顯示可回聽位置。它不複製音符，也不把自己的預測當標準答案。新分析產生的建議譜會包含提示，既有完成的歌曲仍保留原結果。
5. **合成音訊訓練**：固定種子生成 288 段已知音符錄音，混合不同泛音、非線性失真、延遲與雜訊，以完全不同的音色組做回歸測試。合成回歸 F1 為 0.7763；在 12 段真實錄音的 1,980 個預測音上，低分提示有 1,279 個，其中僅 177 個實際未對上參考音，錯音提示精確率約 0.138。這個模型不會放進正式建議譜，後續需用獨立的真實人工標註做校準。

要離線重跑實驗，可使用 `tools/benchmark_corpus.py --infer --context-review --reuse-raw-report ...`。`CHORDLAB_CONTEXT_REVIEW=true` 可讓新分析啟用第 1–3 項實驗，但目前預設 `false`。合成訓練命令為 `.venv-guitar/bin/python tools/train_note_plausibility.py /mnt/sdb/chordlab/benchmarks/new-note-experiment`；模型保存在該目錄，正式服務沒有裝載。成對比較可用 `tools/compare_recognition_reports.py`，單獨切點測試可用 `tools/benchmark_chord_boundaries.py`。

曾評估 [Klangio 的刷弦與和弦模型](https://github.com/Klangio/guitar-strumming-transcription)。其公開分類表只有 24 種大／小三和弦，對七和弦、sus、slash bass 等不夠完整；目前沒有將其結果直接套到所有歌曲。若要專門做木吉他刷奏分支，需要另外取得模型權重、跑相同錄音比較並確認授權。
